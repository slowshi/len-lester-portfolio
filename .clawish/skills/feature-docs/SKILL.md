# Feature Docs (portfolio)

Maintains `.clawish/features/` — one Markdown file per area.

## Portfolio feature areas

- `content-and-constants.md` — constants.tsx, Experience vs Projects
- `resume-markdown.md` — resume vs site, PDF export
- `styling-and-theme.md` — Monokai, Tailwind 4, ProjectCard
- `scribblevet-copy.md` — ScribbleVet copy boundaries
- `laslow-labs-copy.md` — Laslow Labs apps and links

## Format

Follow [`references/TEMPLATE.md`](references/TEMPLATE.md).

During normal sessions write to `memory/` first; promote when ready.

## Do NOT document

Things obvious from reading `constants.tsx` or component source — file inventories, generic React patterns.
